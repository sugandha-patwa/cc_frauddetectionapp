❓ TROUBLESHOOTING

Problem: "Python not found"
Solution: Install Python from https://python.org/downloads
          Make sure version is 3.8 or higher

Problem: Setup script won't run
Solution: Windows - Right-click → "Run as administrator"
          Mac/Linux - Run: chmod +x setup.sh && ./setup.sh

Problem: "Port 5000 already in use"
Solution: Edit app.py, change port from 5000 to 5001
          Then use: http://localhost:5001

Problem: Virtual environment not activating (Windows)
Solution: Run PowerShell as admin, then run:
          Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser
